# Forge 8.16.1

Forge 8.16.1 fixes concurrent P2P identity use discovered while integrating a
multi-node validator. It is a patch release over Forge 8.16.0 and does not
change public source contracts, protocol bytes or persisted database layouts.

## P2P Identity Lifetime

`forge.net.p2p` now parses configured identity key material once during node
construction. TLS, Noise, PubSub, rendezvous and relay signing reuse that
immutable node-owned value instead of parsing the same PEM concurrently for
each operation.

This removes allocator corruption observed during simultaneous direct TCP/TLS
handshakes. Insecure QUIC-only test nodes may still omit signing material; an
operation that requires a signature fails with the existing typed identity
error.

## Verification

The P2P suite covers concurrent direct TCP/TLS handshakes, secure echo traffic
and insecure QUIC-only construction. The complete 179-case suite also passes on
macOS ARM64 with allocator scribbling and guard edges enabled.

## Migration And Compatibility

No migration is required. Consumers should rebuild against Forge 8.16.1.
