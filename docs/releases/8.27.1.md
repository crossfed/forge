# Forge 8.27.1

Forge 8.27.1 fixes the `forge.chain.transaction.builder` C++ module on Linux
toolchains that do not expose fixed-width integer declarations transitively.
The module now includes `<cstdint>` directly before exporting functions that
use `std::uint16_t` and `std::uint32_t`.

This patch does not change public API, wire formats, persisted values or
runtime behavior.

## Validation

The focused `forge_chain_transaction` target passes locally with Clang 22.1.8.
The missing direct include was identified by the Storlane focused Ubuntu 24.04
Contract SDK matrix with Clang 22 and libstdc++ 15. Forge GitHub CI and Codex
review were intentionally not run for this patch release.
