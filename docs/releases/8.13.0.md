# Forge 8.13.0

Forge 8.13.0 adds neutral blockchain construction primitives without adding a
controller, execution runtime, persistence policy or product-specific chain
model. The new Chain libraries and their public APIs are Preview.

This release is additive. Existing package components, modules, Raw and Variant
representations, protocol records and persisted layouts are unchanged.

## New Chain Components

| Target | Package component | Responsibility |
| --- | --- | --- |
| `forge_chain_quorum` | `chain_quorum` | Deterministic checked weighted-quorum evaluation |
| `forge_chain_fork` | `chain_fork` | Generic thread-safe fork graph with indexed best-rank selection |
| `forge_chain_savanna` | `chain_savanna` | Operational finality state, policy validation and typed QC verification |

Consumers request only the leaves they use:

```cmake
find_package(Forge CONFIG REQUIRED
   COMPONENTS chain_quorum chain_fork chain_savanna)

target_link_libraries(app PRIVATE
   Forge::forge_chain_quorum
   Forge::forge_chain_fork
   Forge::forge_chain_savanna
)
```

The new public module groups are:

- `forge.chain.quorum.{types,evaluate,exceptions}`;
- `forge.chain.fork.{types,graph,exceptions}`;
- `forge.chain.savanna.{types,policy,finality_core,qc,validation,rank,exceptions}`.

`forge_chain_savanna` uses explicit operational block references and does not
import `forge.chain.protocol`. Product block types, genesis, producer policy,
execution, admission, persistence, networking and controller lifecycle remain
downstream responsibilities.

## BLS Verification

`forge_crypto_bls` adds proof-of-possession validation and grouped aggregate
verification. Savanna uses this typed API instead of accessing the BLS vendor
implementation directly.

Existing BLS values and serialized forms are unchanged. Savanna QC layouts,
finality digest preimages and their golden fixtures are compatibility
invariants even while the surrounding API remains Preview.

## Documentation Direction

The transport-neutral remote Chain state documents added in this release
describe a future implementation direction. They do not add a remote database,
new public module, API contract or plugin.

No source or storage migration is required for Forge 8.13.0.
