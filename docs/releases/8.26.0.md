# Forge 8.26.0

Forge 8.26.0 replaces the public raw authenticated-state query surface with
typed table and account synchronization. Existing authenticated AVL+, finality
binding and proof algorithms are unchanged.

## Typed State Synchronization

`forge.chain.api.state` 2.0 adds bounded `get_table_changes` and
`get_account_changes` operations. Responses contain typed per-block mutations,
audited state projections and opaque cursors bound to the chain, method,
finalized anchor and selector set. The raw and verified clients, HTTP and P2P
descriptors, capabilities, limits and package consumers expose the same
contract.

Table synchronization returns primary rows as canonical bytes with payer
metadata. Account synchronization returns complete account state and canonical
authorities, including thresholds, weighted keys and accounts, waits and
permission parents.

## Compatibility

This release contains an approved pre-stable source and API break. Public
`get_point`, `get_range`, `get_changes`, their protocol DTOs and the public
`history_lost` Chain API error are removed without aliases or legacy routes.
Raw proof primitives remain local to the audit-verifier boundary.

Migration is mechanical: consumers replace raw canonical-key decoding with
`get_table_changes` or `get_account_changes`, treat cursors as opaque bytes and
handle `history_unavailable` by rebuilding from a current finalized anchor.
Persisted authenticated-state nodes and proof hashing do not change.

## Validation

Local ARM64 validation covers the full build, Chain Protocol/API tests, typed
cursor binding and adversarial proof cases, installed package relocation,
structure and formatting gates. CI was intentionally not run for this release.
